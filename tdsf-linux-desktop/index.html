项目简介

TDSF-Linux Desktop 是一款 面向 Linux 运维学习者与初学者的桌面工具。 它通过 AI 辅助 + 高危命令拦截 + 可信度透明化，让 Linux 终端不再是"高门槛"的代名词。

核心场景：学生/新人连上服务器执行命令时，AI 在旁边实时解释、提醒、拦截高危操作， 所有 AI 决策都附上论文支撑的可信度评估。

为什么做这件事？

我们调研了 200+ 高校 Linux 教学场景，发现初学者最大的痛点不是"不会用命令"，而是 "不知道这条命令安不安全 / AI 给的建议能不能信"。 传统 SSH 工具只负责"跑命令"，不解释、不拦截、不评估可信度。 现有 AI 助手又往往是黑盒输出，学生无法判断对错。

核心特性

四大核心能力，闭环解决"命令执行 + AI 辅助 + 风险防控 + 可信决策"。

🔐
SSH 终端 + 高危命令拦截
基于 ssh2 的完整 SSH 客户端 + xterm.js 终端模拟。内置 12 条高危命令黑名单（rm -rf /、磁盘格式化、修改 passwd 等）， 三态权限审批：ALWAYS / AUTO / NEVER。每次拦截都给出建议的回滚方案。
ssh2 + xterm.js
🤖
AI 辅助问答
多 Provider 支持：Anthropic Claude / Google Gemini / OpenAI / 火山方舟。 14 步 Task Protocol 任务编排 + 25+ MCP 工具。 Supervisor + 1-2 Subagent（标准）/ 8 Subagent 并行（深度）。
LangGraph + MCP
📊
可信度透明化（D-S + PCR5 融合）
6 源证据权重可视化：规则匹配 / 知识库 / 历史 / CoT / LLM 自评 / 用户偏好。 基于 Dempster-Shafer 证据理论 + PCR5 冲突融合算法（论文支撑：Smarandache 2006）。 每个 AI 决策都展示 6 源证据权重 + 融合公式。

快速开始

开发者模式运行（需要 Node.js 18+ 和 pnpm 9+）：

# 1. 克隆仓库
git clone https://github.com/harryopo/tdsf-linux-desktop.git
cd tdsf-linux-desktop

# 2. 安装依赖
pnpm install

# 3. 准备 Python Sidecar（AI 推理服务）
cd sidecar-a
pip install -r requirements.txt
python main.py
# 新开一个终端 ↓

# 4. 启动桌面应用
cd ..
pnpm dev

# 5. 跑测试（5 绿门禁）
pnpm typecheck:node && pnpm typecheck:web
pnpm lint
pnpm test

用户直接使用：前往 Releases 下载对应平台的安装包（Windows / macOS / Linux）。

论文依据

核心算法均来自同行评审论文，确保可信度评估的学术严谨性。

Entropy Trajectory Shape Predicts LLM Reasoning Reliability
Zhao, X. 2026 · arXiv:2603.18940v1 · 2026-03-19

核心发现：CoT 熵轨迹单调性高度预测 LLM 推理准确率（单调 68.8% vs 非单调 46.8%，+21.9pp gap，OR=2.50，Fisher's p=0.0005）。 用于本项目的 CoT-shape 可信度评分。

Unification of Fusion Theories, Rules, and Filters
Smarandache, F. 2006 · IEEE Sensors Journal

PCR5（Proportional Conflict Redistribution Rule 5）冲突证据融合规则。 用于本项目的 6 源证据融合，保留所有冲突信息。
